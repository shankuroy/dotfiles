# dotfiles

These days I value simplicity.

I have a private dotfiles repo I started about 4 years ago which contains a boatload of config that I don't really want to keep building on.

This repo aims to distill that into a more defaults-first/minimal approach.

These dotfiles are managed via [stow](https://www.gnu.org/software/stow/manual/stow.html). See the `scripts/bootstrap` folder to get started.
